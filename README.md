# Blog Reader

Public-facing blog frontend where anyone can read posts and logged-in users can comment and like.

## Features
- Browse all published posts
- Read full post with comments
- Login/signup
- Leave comments when logged in
- Like posts when logged in

## Tech Stack
- React + Vite
- React Router
- JWT stored in localStorage

## Live Demo
https://blog-reader-top.netlify.app

## Setup
1. Clone the repo
2. `npm install`
3. Create `.env` with `VITE_API_URL=http://localhost:3000`
4. `npm run dev`
